# Varkala stays and cafes

A page for travelers looking at Varkala, Kerala. It lists stays and cafes, puts each address on an OpenStreetMap pin, and keeps paid-sounding or bot-like notes out of the default list.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173/

`npm run build` writes the static site to `dist/`.
